<p class="wp-block-paragraph">Bored of learning python the regular way? Make a command line interface Hangman game and learn while you&#8217;re at it. </p>



<p class="wp-block-paragraph">First try out the game for yourself! Run the following in your terminal,</p>



<pre class="wp-block-code"><code>pip install hangman-ultimate
hangman-ultimate</code></pre>



<p class="wp-block-paragraph">Never played the chalk board game of Hangman before? Rules are simple, you have to guess the name of a random animal letter by letter. Every wrong guess of a letter will bring the man closer to hanging. In retrospection, the game is a little dark for me to have played as a kid. </p>



<p class="wp-block-paragraph">Alternatively, you can download the code from <a href="https://github.com/devarshi16/HangMan">here</a>.</p>



<p class="has-light-gray-color has-dark-red-background-color has-text-color has-background wp-block-paragraph">Remember to like this post and start my Repository on GitHub if this post helped you!</p>



<p class="wp-block-paragraph">Tear apart the code and make sure you have learnt the following at the end of it,<br>1. Opening a file and reading from it line by line.<br>2. Making multi-line strings.<br>3. Python Classes and Class instances(objects).<br>4. Class fields(variables) and methods(functions).<br>5. Passing class objects to functions.<br>6. Shared and non-shared fields(variables) amongst objects of same class. <br>7. Calling system(terminal) commands via the python script.<br>8. Catching an error using try except block.<br>9. Making basic command line animations.<br>10. Making programs compatible with both python 2 and python 3.<br>11. Pip packaging your python programs!</p>
